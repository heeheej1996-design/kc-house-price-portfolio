# 데이터 구조 파악 SOP (Standard Operating Procedure)

새 데이터를 회귀분석에 쓰기 전, 아래 5개 항목을 이 순서대로 확인한다. 원본 파일은 절대 수정하지 않고 읽기 전용으로만 연다.

## 절차

1. 행·열 수 확인
2. 컬럼명과 자료형(dtype) 확인
3. 컬럼별 결측 개수/비율 확인
4. 수치형 컬럼의 기초 통계(count, mean, std, min, 25/50/75%, max) 확인
5. 범주형 컬럼의 값 종류(고유값 수)와 값별 개수 확인
